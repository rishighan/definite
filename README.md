# Definite

A dictionary extension for Ulauncher.

## Usage

Type `def <word>` in Ulauncher to get definitions.

## Installation
```bash
git clone <repo> ~/.local/share/ulauncher/extensions/definite
```

Restart Ulauncher.

## Features

- Multiple definitions per part of speech
- Phonetic pronunciation
- Usage examples
- Click to copy definitions

## Requirements

- Ulauncher
- Python 3
- `requests` library

## API

Uses [Free Dictionary API](https://dictionaryapi.dev/)
